# Сборщик тиков RTS и MIX из QUIK

Сборщик записывает обезличенные сделки ближайших к экспирации контрактов RTS и MIX в недельные базы SQLite. По умолчанию базы создаются в `C:\data_quote\tick_data` при поступлении первых сделок.

## Запуск

1. Откройте PowerShell в корне проекта и запустите Python-сборщик. Он создаст папку `spool` для временных пакетов. Сторонние Python-пакеты не требуются.

   ```powershell
   .\.venv\Scripts\python.exe .\collect_ticks.py
   ```

2. В подключённом QUIK включите получение обезличенных сделок для нужных серий класса `SPBFUT`. На новых версиях эта настройка находится в **F9 → Программа → Получение данных → Обезличенные сделки**. Чтобы данные продолжали поступать после экспирации, включите также следующие серии RTS и MIX или весь класс `SPBFUT`, если это удобно при вашем потоке данных. Проверьте, что в таблице обезличенных сделок QUIK появляются строки по нужным сериям. [Настройки потока данных QUIK](https://forum.quik.ru/forum1/topic7006/)
3. В QUIK откройте окно **Lua скрипты**, добавьте `export_ticks.lua` из корня проекта и нажмите **Запустить**. Оставьте Python и Lua запущенными во время сбора. [Документация и примеры QLua](https://arqatech.com/ru/support/files/other/)

Для штатной остановки сначала остановите Lua-скрипт в QUIK, затем нажмите `Ctrl+C` в Python. Оставшиеся готовые пакеты будут импортированы при следующем запуске.

## `export_ticks.lua`

Скрипт читает новые строки `all_trades` с момента запуска. Для каждого семейства он выбирает стандартный фьючерс с ближайшей датой `mat_date` в справочнике QUIK. Время сделки сравнивается со временем экспирации, поэтому в день исполнения в 19:00 МСК выбор переключается на следующую серию. Критерий выбора — дата экспирации. Мини-фьючерсы и опционы исключаются по классу и коду инструмента. [Коды срочных контрактов](https://www.moex.com/s205) · [Карточка RTS](https://www.moex.com/ru/derivatives/futures-on-indices/riz6) · [Карточка MIX](https://www.moex.com/ru/derivatives/futures-on-indices/mxz6)

Параметры запуска в QUIK не требуются. Скрипт обновляет справочник каждые 5 секунд. Если по одному семейству не хватает дат экспирации, другое семейство продолжает записываться. Готовые пакеты `.tsv` появляются в `spool` рядом со скриптом. Перед запуском откройте Python-сборщик командой из раздела «Запуск». Для получения пропущенных сделок за время остановки Lua нужна отдельная историческая выгрузка.

## `collect_ticks.py`

Скрипт читает только готовые `.tsv`, фиксирует сделки транзакциями и удаляет пакет после успешной записи во все нужные базы. Повтор пакета безопасен благодаря ключу `(contract_code, exchange_ts_us, trade_num)`. Этот же ключ обслуживает выборки по коду контракта и времени. Блокировки защищают каталоги пакетов и баз от одновременного запуска нескольких сборщиков.

| Параметр | Назначение |
| --- | --- |
| `--data-dir` | Каталог баз. По умолчанию `C:\data_quote\tick_data`. |
| `--spool-dir` | Каталог готовых пакетов. По умолчанию `spool` в корне проекта, куда пишет Lua-скрипт. |
| `--once` | Обработать готовые пакеты и завершить работу. |

Разовый импорт пакетов в каталог по умолчанию

```powershell
.\.venv\Scripts\python.exe .\collect_ticks.py --once
```

Импорт из другого каталога в отдельное хранилище

```powershell
.\.venv\Scripts\python.exe .\collect_ticks.py --once --spool-dir C:\tick_replay --data-dir C:\data_quote\tick_replay
```

Повреждённый пакет остаётся в `spool`. В PowerShell появится сообщение с именем файла. После исправления пакета перезапустите Python-сборщик для повторного импорта. При временном сбое записи постоянный сборщик повторяет попытку сам.

## Формат базы

Имя файла содержит дату понедельника по МСК, например `ticks_2026-11-16.sqlite`. Таблица `trades` содержит шесть полей.

| Поле | Значение |
| --- | --- |
| `contract_code` | Код серии. Префикс `RI` соответствует RTS, `MX` соответствует MIX. |
| `exchange_ts_us` | Целое число микросекунд от `1970-01-01 00:00:00 UTC`. Например, `1795158000123456` соответствует `20.11.2026 10:00:00.123456 МСК`. |
| `trade_num` | Номер сделки. |
| `price` | Цена сделки. |
| `qty` | Количество контрактов в сделке. |
| `flags` | Исходные флаги QUIK. |

При открытии старой недельной базы для записи сборщик переводит текстовые метки МСК в целые микросекунды UTC в одной транзакции. После миграции место внутри файла доступно для повторного использования. `VACUUM` уменьшает размер самого файла.

Активная база работает в режиме WAL. Для резервного копирования во время сбора используйте SQLite Backup API. [Резервное копирование SQLite](https://sqlite.org/backup.html)

Команды проверки приведены в [tests/README.md](tests/README.md).
