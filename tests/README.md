# Проверки сборщика

`test_collector.py` проверяет границу недельных файлов по МСК, перевод времени в целые микросекунды UTC, формат локального времени в сводке импорта, миграцию старых баз, её откат при ошибке, повторный импорт, блокировку параллельного чтения очереди и отказ при повреждённом пакете. Дополнительная проверка загружает Lua 5.4 из QUIK, подставляет тестовые сделки и проверяет ожидание справочника отдельно по RTS и MIX, смену ближайших фьючерсов в момент экспирации, финальный пакет при остановке и запись пакетов в SQLite.

`test_show_tick_sqlite_base_samples.py` проверяет выбор самых ранних и поздних сделок из разных недель, отображение времени по МСК с пометкой `отсутствует в БД` и чтение подтверждённых данных при активной записи в WAL.

Команда из корня проекта в PowerShell

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Для проверки QLua перед запуском укажите путь к DLL своей установки QUIK.

```powershell
$env:QUIK_LUA_DLL = 'C:\QUIK\lua54.dll'
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```
